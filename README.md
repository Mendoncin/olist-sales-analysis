# Olist Sales Analysis 



## Dataset

Este projeto utiliza o **Brazilian E-Commerce Public Dataset by Olist**, disponibilizado publicamente no Kaggle.

**Fonte:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

O conjunto contém informações sobre pedidos, clientes, produtos, vendedores, pagamentos, avaliações e localização geográfica de operações de e-commerce no Brasil.

Os arquivos CSV originais são armazenados localmente em `data/raw/` e não são versionados no GitHub.

Os dados tratados e transformados serão armazenados em `data/processed/`.
